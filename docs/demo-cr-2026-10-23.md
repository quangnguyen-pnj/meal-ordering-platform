# Change requests of 2026-10-23 – how to demo each item

> The "Automated" references name test files of the NestJS API, which was removed in J3; their Java ports are listed in [demo-j2.md](demo-j2.md) and [demo-j3.md](demo-j3.md).

What changed is in [decisions.md](decisions.md) ("Change requests of 2026-10-23"). Setup and accounts are as in [demo-p0.md](demo-p0.md) to [demo-p2.md](demo-p2.md); this added migration V3 (`V3__change_requests.sql`).

```bash
pnpm install
pnpm db:seed
pnpm dev                    # API :3001, web :3000
```

Accounts (PIN `123456`, change at first sign-in): employee `PNJP000001`, dept admin `PNJP000002`, HC admin `PNJP000003`, system admin `PNJP000004` (sets fake time with `PUT /api/dev/clock`).

Automated proof:

```bash
pnpm --filter @meal/shared test   # rules/menu, library-import, registration-import, mapping, time
pnpm --filter @meal/web test      # menu-builder-store (draftGaps), org-filter
TEST_DATABASE_URL=postgresql://…/meal_test pnpm --filter @meal/api test   # menu, registration, admin, org e2e
```
